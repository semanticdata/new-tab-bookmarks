# Changelog

## 1.6.0

- Add unified browser API detection for Chrome, Firefox, and Edge compatibility
- Add comprehensive error handling and JSDoc documentation to all scripts
- Add semantic `<time>` elements for date and clock displays
- Add proper ARIA attributes for accessibility compliance
- Add CSS custom property fallbacks and organized stylesheet sections
- Add `font-display: swap` to all fonts for better loading performance
- Add Content Security Policy and font preloading for security and performance
- Fix background script reference error preventing new tab opening
- Fix script loading order to resolve dependency issues
- Improve notes saving performance (increase debounce from 10ms to 500ms)
